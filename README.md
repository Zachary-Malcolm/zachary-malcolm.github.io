# zachary-malcolm.github.io

My portfolio site: **https://zachary-malcolm.github.io**

A single page about me, my projects, skills and education. Plain HTML, CSS and JavaScript with no build step, hosted on GitHub Pages.

## Files

| File | What |
|---|---|
| `index.html` | All the page content |
| `styles.css` | Dark theme, layout and animations |
| `script.js` | Starfield background, typing effect, scroll reveals, videos that play only while on screen, Vega gallery |
| `media/` | Screenshots and short screen recordings of each project |

## Updating it

Edit the files, then commit and push to `main`. GitHub Pages republishes the site within a minute or two.

To preview locally, run `python -m http.server 8810` in this folder and open http://localhost:8810.
